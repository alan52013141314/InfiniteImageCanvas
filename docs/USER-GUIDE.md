# 無限圖片畫布 v0.3.0：操作說明

直接執行 InfiniteImageCanvas-v0.3.0.exe（本機亦提供 InfiniteImageCanvas-latest.exe），不需安裝。使用可寫入的資料夾存放程式。

## 語言及版本

「設定 → Language / 語言」可選 English 或繁體中文，立即套用並記住選擇。舊版設定預設維持繁體中文。視窗標題及設定中會顯示版本號；此號碼獨立於版面檔案格式版本。

## 匯入與排列

- 從檔案總管拖入 PNG、JPG／JPEG、WebP、BMP 或 GIF；GIF 會播放動畫。
- 可拖入整個資料夾，或點「資料夾」，會掃描所有子資料夾內的支援圖片；掃描可取消。
- 同一批超過 100 張時會顯示準備匯入的總數，確認後才整批加入；取消不改動畫布。100 張及以下直接加入。
- 「匯入圖片」可一次選取多張；「貼上」或 Ctrl+V 可加入剪貼簿截圖。
- 拖入單張時，滑鼠落點就是圖片左上角。
- 多張從落點開始分行排列，同行左右貼齊；每行張數為總數平方根向上取整。2 張是 2；3 張是 2＋1；4 張是 2＋2；5 張是 3＋2。
- 不同尺寸保持原尺寸與比例，每行使用最高圖片決定下一行起點。選檔匯入從目前視野中心開始。
- 「設定」可選依載入順序或隨機順序，只影響下一批匯入，不改動原本的圖片。

## 介面

頂部保留圖片匯入、資料夾、貼上、保存、設定及全螢幕。新建、開啟與另存位於「檔案」；復原、重做及圖片層次位於「編輯」。檔名前的實心綠點表示尚有變更，空心圓表示已保存。底部狀態若被截短，可停留游標查看完整內容。

全螢幕時上下工具列預設隱藏；滑鼠移到上方／下方工具列區域才浮出，移開後隱藏。開啟選單期間上方工具列會保留，畫布不因工具列顯示而移位。按 F11 隨時返回一般視窗。

## 操作

| 動作 | 操作方式 |
|---|---|
| 移動圖片／選取群組 | 左鍵拖曳 |
| 平移畫布 | 按住滑鼠中鍵拖曳 |
| 縮放畫布 | 滑鼠滾輪，以游標所在位置為中心 |
| 縮放圖片 | 選取後拖四個角點，保持比例 |
| 多選 | Shift／Ctrl＋點選，或在空白處框選 |
| 全選 | Ctrl+A |
| 刪除選取圖片 | Delete 或「編輯 → 刪除選取圖片」；不刪除原圖檔案 |
| 圖片層次 | 選取後在「編輯」選擇「移到最前／移到最後」 |
| 復原／重做 | Ctrl+Z／Ctrl+Y，也可 Ctrl+Shift+Z |
| 顯示整個版面 | Home 或「顯示全部」 |
| 無邊框全螢幕 | F11 或「全螢幕」；再次操作返回視窗 |
| 保存／另存 | Ctrl+S／Ctrl+Shift+S |
| 開啟版面／新建 | Ctrl+O／Ctrl+N |

## 保存

版面格式為 `.icanvas`，預設位置是執行檔旁的 `save file`。

首次手動保存使用 `canvas_yyyyddMM_01.icanvas`，例如 2026 年 10 月 9 日為 `canvas_20260910_01.icanvas`；同日新檔依序增加序號。之後更新同一份檔案。

第二行的每個分頁都是獨立版面，保留各自的視野、選取、復原記錄及保存位置。「編輯」位於第一行。按 + 或「新建」新增分頁；開啟檔案會新增分頁，已開啟的檔案則切換至現有分頁。啟動會恢復全部分頁及最後使用中的分頁。

每 1 分鐘有變更才自動保存，包含背景分頁；正常關閉程式或按 Alt+F4 會保存全部分頁。未命名的版面分別使用 `previous_canvas.icanvas`、`previous_canvas_02.icanvas` 等恢復檔，不會共用保存位置，也不會以新分頁覆蓋既有恢復檔。之後首次手動保存仍使用日期名稱。

按分頁的 × 會詢問「保存後關閉／不保存並關閉／取消」。「不保存」只放棄最近一次成功保存後的變更，不會撤回之前的自動保存或刪除既有檔案。關閉最後一個分頁後會留下空白分頁。

保存失敗會保留視窗及內容，選「重試保存」或「另選保存位置」處理。強制結束只能恢復到最近一次成功保存的狀態。

## 引用與封裝

- 預設「引用原圖」：版面檔較小，需保留原圖的路徑。找不到原圖時顯示缺圖位置與路徑，其餘圖片仍可使用。
- 「封裝原圖」：保存成含原圖的單一版面檔，適合攜帶或備份；GIF 原始動畫保留。
- 切換模式後，下一次成功保存會使用選定模式。
- 剪貼簿圖片及開啟封裝檔所需的素材存放在 `assets`。引用模式可能使用這些素材，請連同版面一起保留。
- 若 exe 資料夾不可寫，另選可寫位置保存。啟動恢復設定必要時會保存在 `%LOCALAPPDATA%/InfiniteImageCanvas`。

## 容量

不設圖片張數或原圖解析度上限。畫面使用按需解碼、視野裁切及有限的顯示快取；顯示預覽不會改變原圖或封裝的內容。實際可載入的圖片仍受記憶體與顯示硬體限制；解碼資源不足會顯示錯誤。
