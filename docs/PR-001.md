## 保存狀態

| 事件 | 規則 |
|---|---|
| 未命名版面首次手動保存 | 在 exe 旁 save file 產生日期與可用序號名稱，成功後設為目前目標。 |
| 已命名版面再次保存 | 更新目前檔案，不產生新序號。 |
| 未命名版面定時保存 | 寫入 previous_canvas，仍維持未命名狀態；之後首次手動保存仍提供日期名稱。 |
| 已命名／開啟版面定時保存 | 有變更才更新目前檔案。 |
| 正常關閉 | 等待保存成功才退出；無目前命名目標時寫入 previous_canvas。 |
| 保存失敗 | 保留現有檔案及記憶體中內容，不清除變更標記，不更新目標，顯示重試／另選位置。 |
| 下次啟動 | 恢復最後使用的版面，包含未命名的 previous_canvas。 |

## 必要實作細節

以下是落實既定需求的技術處理，不是新增功能：

- 引用模式的剪貼簿截圖沒有來源檔案，必須先將圖片持久化至保存資料夾內受管理的素材，再於版面引用；不引用臨時剪貼簿記憶體。
- 封裝模式保留原始 GIF 資料以恢復動畫；引用模式若來源移動或刪除，顯示缺圖提示及原路徑，不讓整個版面開啟失敗。
- 設定切換保存模式後，下次成功保存使用選定模式；原本封裝圖片若轉為引用模式，先安全輸出素材。轉換失敗不得破壞原版面。
- 啟動恢復的記錄及設定與免安裝資料一同持久化；exe 資料夾不可寫時依保存失敗流程處理，不悄悄丟失資料。
- 定時保存只保障最近一次成功保存的狀態；強制終止不一定能執行關閉保存。
- 大圖與多圖使用按需載入、視野裁切與有限資源快取；不以固定張數或解析度門檻拒絕圖片。資源不足時清楚回報並保留版面。

## 驗收

1. Windows 10／11 x64 可直接啟動免安裝版，介面為繁體中文、深色。
2. 三種匯入方式可用；五類圖片格式可開啟，GIF 能播放且重開後仍有動畫。
3. 中鍵平移、滾輪縮放與圖片拖移、角點縮放相互獨立；多選、刪除、前後層及復原／重做正確。
4. 保存重開後，圖片、位置、尺寸、堆疊及視野一致。
5. 引用模式不複製已有來源的原圖；封裝模式在移走來源後仍可完整開啟。貼上截圖重開後不遺失。
6. 檔名為 yyyy／dd／MM；相同日期的新檔序號遞增，既有檔持續更新。
7. 未命名、已保存、開啟既有檔案三種狀態的手動／定時／關閉保存均寫到正確目標。
8. 每 60 秒有變更才保存；未變更不重寫。啟動恢復最近一次成功保存的版面。
9. 寫入失敗仍保留視窗及內容，可重試／另選位置；既有有效版面不被半寫入檔毀損。
10. 不設定圖片張數與解析度上限。用逐級增加負載的實測記錄硬體、記憶體及操作表現，不承諾無限硬體容量。
11. 按鈕與 F11 均可進入／離開無邊框全螢幕；返回一般視窗後畫布與圖片資料不變。
12. 單張拖入左上角對準滑鼠；2～5 張的批次排列符合範例。不同尺寸圖片不重疊、同行左右緊貼；順序／隨機設定持久化。
13. 資料夾拖入及選擇皆可匯入圖片；驗證 100 張直接加入、101 張等待確認、取消零加入、確認整批加入。掃描不凍結介面，非圖片及無法讀取的檔案妥善處理。
