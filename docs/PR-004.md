# PR-004: v0.3.1 tab management and appearance

Date: 2026-10-09
Status: implemented and verified.

- Join tab label and close button inside one continuous outline.

- Drag tabs onto other tabs to change order without changing document state or the active document; restore order on restart.
- Preserve English/Traditional Chinese, fullscreen, per-tab autosave and failure recovery.
