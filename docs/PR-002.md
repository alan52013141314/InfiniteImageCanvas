# PR-002: v0.2.0 language support and public release

Date: 2026-10-09

User request: support English and Traditional Chinese, display a version number, and publish to a public Git repository.

Acceptance:
- Settings offers English / 繁體中文, applies immediately, and persists across restart. Existing settings default to Traditional Chinese.
- Toolbar, menus, hints, dialogs, counts, status and application-owned errors support both languages. OS-generated errors and file names retain their original content.
- Cargo is the version source; v0.2.0 appears in the window title and settings. The canvas format version remains independent.
- Verify both languages at the minimum window size, settings persistence and existing functionality.
- Publish source and documentation to the authenticated user's public InfiniteImageCanvas repository; exclude personal canvases, assets, machine-specific test outputs, build directories and credentials. Publish a versioned Windows release archive.
- No unrelated features or server. A public repository does not by itself grant a new software license.
