# PR-003: v0.3.0 tabs

Date: 2026-10-09
Status: implemented and verified by automated tests; native visual verification unavailable this round.

Confirmed request:
- Move Edit / 編輯 to the first toolbar row.
- Add tabs, switchable from the second UI row.
- Preserve English / Traditional Chinese support and fullscreen edge controls.

Confirmed behavior:
- Each tab is an independent canvas file, retaining its view, selection and undo/redo history while switching.
- New/Open creates a tab; opening an already-open file selects its existing tab to avoid simultaneous writers.
- Startup restores all tabs and the active tab.
- Closing a tab prompts Save / Don't save / Cancel. Don't save discards only changes since the last successful save (autosave remains enabled).
- Unnamed recovery files use previous_canvas, previous_canvas_02, etc., without sharing a target.
- Normal application close retains the existing automatic-save behavior: save all open tabs and restore them on startup.
- First-row Edit and second-row scrollable tabs remain bilingual and compatible with fullscreen edge controls.

No personal saves or test assets are included in public delivery.
