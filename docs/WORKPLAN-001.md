## 摘要與執行規則

依已確認 PR 建立 Rust Windows 桌面圖片畫布，涵蓋匯入、GIF、圖片操作、兩種保存模式、定時保存及启动恢復。每次只有一個目標執行；使用者已授權完成程式，正在實作與驗證；不建立伺服器。

## 目前已知

- 使用者確認專案名稱與資料夾、Windows 10／11 x64、繁體中文深色介面及免安裝交付。
- 已確認每 1 分鐘有變更才保存；其餘行為見 PR-001。
- 採用 eframe／egui 0.31.1、OpenGL、image 解碼、版本化 ZIP 版面（.icanvas）；Rust 1.99.0。驗證結果見 VERIFICATION.md。
- 圖片不設人為張數與解析度上限，採逐級負載量測，不以固定容量作為功能限制。

## T1：桌面架構

目標：查核 Rust 工具鏈及候選 GUI／繪圖方案的官方文件，選擇支援 Windows 10／11、原生拖入、剪貼簿、GIF、自訂畫布及關閉攔截的方案。

工作：建立最小視窗及驗證樣本；確認高解析度圖片可採分塊或分級顯示，避免直接受單張 GPU 紋理尺寸限制。記錄架構與建置方式。

完成條件：目標 Windows 可啟動視窗，驗證檔案拖入、中鍵事件、圖片繪製與 GIF 播放可行。此階段不延伸為額外產品功能。

## T2：匯入與畫布

追加需求：資料夾拖入與選擇、背景掃描、超過 100 張的批次數量確認；使用者已確認遞迴包含所有子資料夾。新增 100／101 邊界、取消、確認及資料夾混合內容測試。

追加需求（2026-10-09）：單張落點為左上角；批次按 ceil(sqrt(n)) 列數緊貼排列，測試 1～5 張及不同尺寸。加入可持久化的順序／隨機匯入設定，隨機化只處理新批次。

目標：支援拖入、選檔與 Ctrl+V 截圖，以及 PNG／JPEG／WebP／BMP／GIF；實作中鍵平移、滾輪縮放的無邊界畫布。

工作：將世界座標與視野變換分離；背景載入、可視區裁切、有限解碼／紋理快取及 GIF 幀排程，避免預先解碼所有圖片或所有動畫幀。超大圖依需求使用分塊或分級顯示，不修改來源。

驗證：座標往返、不同倍率的游標定位、多圖批次拖入、透明圖、GIF 幀時間、損壞圖片及資源不足。完成條件：所有指定匯入方式可用，資源問題不毀損已有版面，畫布移動不改變物件資料。

## T3：圖片編輯

追加介面需求：以簡潔專業的深色工作區重新整理視覺層級。主要操作集中，次要文件操作移至檔案選單；保持 F11、資料夾按鈕、保存與編輯功能。驗證正常與窄視窗、空白狀態、設定和大量匯入確認。

追加需求（2026-10-09）：全螢幕按鈕與 F11 切換無邊框全螢幕；實測進入、退出及資料保持。

目標：左鍵拖移、角點等比例縮放、多選、刪除、前後層及復原／重做。

工作：建立命中順序與多選狀態；以一次拖移／縮放為一筆歷史操作，定義刪除與層次調整的可逆資料，避免歷史反覆複製大型像素內容。

驗證：重疊圖片選取、不同視野倍率的拖移及縮放、連續復原／重做、多選操作。使用實際視窗與截圖檢查選取邊界、角點及層次。

完成條件：批准的所有操作可用且編輯歷史能恢復對應物件狀態。

## T4：版面與保存模式

目標：預設引用原圖，設定可切换單檔封裝；保存位置為 exe 旁 `save file`。保存完整物件資料與視野。

工作：定義版本化格式及副檔名；以暫存寫入及安全替換保護舊檔。實作 yyyy／dd／MM 及同日序號；剪貼簿圖片先持久化至受管理素材。保存模式切換需處理封裝資料與引用素材的轉換，保留原圖及動畫內容。

驗證：兩模式保存往返、來源移走、缺圖、中文路徑、同日多次新建、模式切換、剪貼簿截圖重開、壞檔及不可寫資料夾。

完成條件：資料往返一致；封裝不依賴外部原圖；引用模式既有原圖不重複複製；失敗不破壞舊檔，不錯誤更新保存目標。

## T5：保存生命週期

目標：每 60 秒有變更才保存、正常關閉保存、預設恢復上次版面。

工作：區分未命名恢復檔 previous_canvas 與手動命名檔，避免自動保存導致首次手動保存失去日期名稱。已開啟版面直接作為目標；允許覆寫 previous_canvas。序列化保存作業，避免定時、手動與退出同時寫入。記錄保存開始時的版本，保存期間新修改不得被誤標為已保存。

驗證：未命名／手動命名／開啟既有檔 × 手動／定時／退出保存；60 秒排程與無變更不寫入；保存中繼續編輯；寫入失敗重試及另選位置；保存後啟動恢復；定時保存後強制結束再恢復。

完成條件：保存目標正確、正常退出等待成功；失敗保留視窗與內容；僅恢復到最近成功保存狀態，不宣稱強制終止仍能執行退出保存。

## T6：效能與交付

目標：交付免安裝 Windows x64 版本及簡短繁體中文操作說明。

工作：逐級增加圖片數、解析度與 GIF 負載，記錄硬體、記憶體及操作表現；檢查長時間操作、不同 Windows 顯示縮放比例、保存中互動與資源釋放。實測負載是證據，不是產品張數／解析度限制。

完成條件：Windows 11 完成啟動及保存驗證，靜態相依檢查確認免安裝執行檔；Windows 10 實測依使用者「noneed」回覆不作交付條件；發布資料含必要執行相依項，說明引用圖片可攜性、封裝設定與保存位置。未能取得的測試環境必須明列未驗證，不虛報通過。

## 全域驗證

建立專案後執行 `cargo fmt --check`、`cargo clippy --all-targets -- -D warnings`、`cargo test`，最終執行 `cargo build --release`；依選定架構調整。自動測試聚焦座標、歷史操作、檔名、格式往返及保存狀態；視覺與桌面輸入以實際 Windows 操作驗證。
